NEURA. UK

Neura UK Build Map

The whole build, from the first live map to a scaled commercial service. There are nine phases, each ending in something you can see running. Eighteen workstreams each own their own code and contracts, so separate engineers can build in parallel. Business decisions and external events act as gates. The plan has no dates or headcount; it shows what depends on what.

Phases end in something visibleEvery phase closes with a running model in the Atlas, not a document.
No two teams own the same codeEach code path, interface contract and data product has exactly one owning workstream.
Teams meet only at contractsCross-team work depends on a frozen, versioned contract, never on another team's code.
Gates are decisions or outside eventsPurple chips (D-n) are business decisions still open; green ones are decided. XG-n are external events such as licences, regulators and signed partners.
