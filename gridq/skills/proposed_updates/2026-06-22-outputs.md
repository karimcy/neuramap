## Proposed text
- Output/rendering layers authoring numbers, or doing arithmetic in the renderer → build them as **extract → format → render**: one extractor reads the record into a typed view model (classification + aggregation of values *already on the record* only — never a new figure), a single formatting module is the *only* place a number becomes a string (value-scaling like £k lives there), and renderers just place strings. Keep the HTML/document generator **arithmetic-free** and assert it (AST scan for `BinOp`/`sum`/`round`). A missing figure renders as an explicit *unavailable(reason)* / *placeholder* label, never a 0/guess. Any prose drafter takes **categorical inputs only** (enums/booleans, never a £-figure) so prose can never carry a record number; ship it deterministic/LLM-free and leave the LLM as an injectable perimeter seam. Regeneration must be byte-identical (no wall-clock in artifacts — time comes from the record).
