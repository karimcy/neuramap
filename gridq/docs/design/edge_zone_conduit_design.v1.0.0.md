## What this is

A generic reference design for one Neura site: zones on the Purdue model, typed conduits between them, a unidirectional gateway (data diode) option towards the facility BMS, and named invariants that every BMS mode must satisfy. It describes no real facility: a site binds to it by hash with every site fact unknown until supplied (see the data asks). The design is machine-readable; later edge packages test against `gridq.edge_design`, not this page.

## A note on spec B1-07

Spec B1-07 reads "unidirectional gateway to the facility BMS where the customer requires it. No data centre will allow BMS writes without it." A unidirectional gateway that only lets data out of the BMS cannot carry a write in, so the two sentences cannot both hold for a write path. This design does not reword the spec. It makes the diode the default (`diode_read_only`, no chiller authority, L2 at most) and reaches L3 through `diode_with_band_offer`: two opposed one-way paths, the inbound one carrying only a chiller band offer that the host's own BMS logic adopts or ignores (D156). The spec owner should confirm the reading.

## Invariants

Checked in every BMS mode when the design is built; a violation refuses the release.

| Invariant | Statement |
| --- | --- |
| `conduit_ids_unique` | conduit ids unique |
| `endpoints_are_zones` | endpoints are zones |
| `purdue_adjacent` | A conduit joins zones whose Purdue levels overlap or are adjacent (NIST SP 800-82r3 5.2.3.1: rules only between adjacent levels; the DMZ sits between levels 3 and 4). |
| `enterprise_reaches_only_dmz` | A zone at level 4 or 5 (the cloud, remote operations, the market partner) connects only to the DMZ: no cloud conduit lands on edge control or anything below it. |
| `boundary_outbound_only` | Every conduit across the site boundary is opened from the site: nothing on site listens. |
| `off_site_reaches_control_only_through_a_break` | With every protocol-break zone removed, no off-site zone reaches any on-site zone: every route from the internet to a controller is terminated and re-originated at least once. |
| `anm_stays_on_site` | The DNO's ANM signal travels only on site and lands on the edge (D119): no conduit carrying it touches the cloud or any off-site zone. |
| `writes_only_into_writable_zones` | A write lands only in a zone that admits that point class: never the UPS, EPMS or DCIM, the meters, the substation, the DNO's RTU or any off-site zone. |
| `writer_opens_and_flows` | The writer opens the session, and data can flow from the writer to the written zone. |
| `write_stage_matches_point_class` | A write's lowest stage is the highest `WRITE_MIN_STAGE` of its point classes, and every chiller or battery write needs the B1-09 safety case. |
| `authority_matches_controls` | A write carries the write allow-list and IC-13 audit; a read-only conduit carries read-only-by-construction; a diode conduit carries the unidirectional gateway and is one way. |
