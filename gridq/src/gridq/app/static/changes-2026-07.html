0 · The goal that ordered all of this

docs/north_star.md — adopted (D27). The battery as a two-sided firming asset, three promises:

  • Customer — “we firm your energy cost”: peak protection, capacity management, a record-backed bill.
  • Grid — dependable contracted flexibility: committed capability actually reserved in dispatch and provably deliverable at end-of-tenor degraded capacity.
  • Lender — a P90 that can be diligenced: firmness-differentiated risk, penalty-aware downside, computed deliverability.

Grounded in a 13-agent deep review (docs/reviews/2026-07-01-deep-review.md) and hardened by a 4-lens adversarial critic panel before adoption. Waves 6–11 are the build sequence; Waves 6 and 7 are now complete, Wave 8 is 4 slices in.

1 · Wave 6 — the adaptive sizing search (issue 016, complete)

DONEThe fixed 3×3 sizing grid is replaced by a continuous power×energy search, with the exact full-year half-hourly LP kept as the only inner evaluator.

  • Continuous domain (SizingDomain): site-scaled bounds from the site’s own peak/connection (never an invented kW); floating C-rate inside a sane 0.5–8 h band. Fixed a real defect: the Latin-hypercube sampler could emit specs outside the duration band — power is now sampled only within the band-feasible window.
  • Exact continuous evaluator: any (power, energy) point scored through the identical dispatch+finance path, with the objective metric recorded per point (levered return / project IRR / priced-floor fallback) so a search can never claim the levered objective while debt terms are absent (B001).
  • Parallel solve harness: one solver per worker, results provably identical to sequential. Measured: 2.0 s/solve → 0.8 s effective at 4 threads (2.5×); a ~1,600-point dense exact grid ≈ 21 min.
  • Dense reference + adaptive refiner + PSO baseline, all budgeted, seeded, step-aware (D32: duration-keyed assumptions keep conservative flooring). Bake-off on the demo site: both search methods reach ≈ zero information loss vs the dense reference (D33).
  • Real-site validation: the wider scope changes the recommendation — 124 kW×4 h → 165 kW×8 h, +10.8% objective vs the shipped 3×3.
Finding C025 (filed, gating). The optimum pins to the 8 h band edge because the placeholder capex is per-MW only — energy is capex-free, so long durations are artificially attractive. The engine default stays on the 3×3 until a £/kWh capex component lands in the assumption library (D33 gate).
