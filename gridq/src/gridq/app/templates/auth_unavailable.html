Google sign-in is not configured on this deployment

This install has no Google OAuth client credentials (GRIDQ_GOOGLE_CLIENT_ID / GRIDQ_GOOGLE_CLIENT_SECRET), so Google sign-in cannot run. That is a deployment constraint, stated plainly rather than worked around.

Your projects are still private. Every browser gets its own workspace: runs you start here are scoped to this browser's signed session cookie, and other visitors cannot list or open them. The trade-off: the workspace is not portable across devices and is lost if you clear cookies (the underlying run data survives on the server; ask the operator to reassign it).

To enable Google sign-in, the operator creates an OAuth Web application client in Google Cloud Console, sets the two environment variables plus GRIDQ_OAUTH_REDIRECT_BASE (the public URL), adds <public URL>/auth/callback as the authorised redirect URI, and restarts the service. Runs claimed by signed-in accounts then follow the account across devices.
